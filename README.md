# Saiko Portfolio — Video Editor

Professional portfolio website with a Supabase-powered admin dashboard. Manage projects from the dashboard; the public **Works** page loads dynamically with live updates.

## Features

- Public portfolio (Home, Works, Contacts)
- Admin dashboard matching the site design (`#111` / `#a6ff00` / Bebas Neue + Poppins)
- Email/password authentication
- CRUD projects with image upload (drag & drop)
- Supabase PostgreSQL + Storage + RLS
- Realtime sync to public works page
